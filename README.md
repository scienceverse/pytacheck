# pytacheck

High-performance Python production engine for the six validated research-check modules from
[Scienceverse/Metacheck](https://github.com/scienceverse/metacheck).

Pytacheck is an in-progress Python port intended for production serving without an R runtime.
Behavioral parity with Metacheck has not yet been established; it will be measured against
checked-in upstream oracle fixtures as implementation proceeds.

The repository currently contains the package and test baseline. The research-check engine,
API, parity harness, and deployment assets will be added in subsequent milestones.
