Metacheck

An Automated Tool to Check for Best Practices in Scientific Articles

Metacheck reads a scientific article and points out where it can be improved. It looks at the reported statistics, the power analysis, the ethics statement and the references. It can also look through the data and code that belong to a paper.

What happens to your files

Your files go to this server and nowhere else, apart from the services named below. Each check runs in its own process. When it is done, the upload is deleted. The report is deleted one hour after it is ready. The pages make no request to other sites, and they keep no cookies.

A PDF is converted to text before it is checked.

Some checks call other services: the Crossref lookup, the retraction and PubPeer checks, and the link of an online repository. They send only what they need, such as a DOI.

Use it from your own code

Everything on this page is also a web interface that a script can use. This sends a paper and saves the report:

curl -F file=@paper.pdf /api/report -o report.html

The same interface can queue a job and poll it. See the documentation of this server for the list of fields.
